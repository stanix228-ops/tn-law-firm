# Премиальный Landing Page и CRM-кабинет для Адвокатской конторы «T&N» (г. Алматы)

Современный, премиальный светлый сайт адвокатской конторы «T&N» с высокой конверсией в звонки и заявки, созданный на основе реальных данных из 2ГИС, а также встроенный Личный кабинет администратора (CRM).

---

## 🌟 Ключевые возможности

### 1. Посадочная страница (`index.html`):
- **Светлый премиальный дизайн:** гармоничное сочетание теплого жемчужно-белого фона, глубокого сапфирового цвета, благородного золота и качественных фотографий.
- **Высокая конверсия (УТП & Доверие):**
  - Опыт ведения процессов до **Верховного Суда РК**.
  - Официальный рейтинг **5.0 в 2ГИС** (53 реальных отзыва).
  - Круглосуточный экстренный выезд 24/7 (задержание, обыск, допрос).
- **3 Ключевых направления защиты:**
  1. *Уголовная защита (УК РК)*
  2. *Арбитраж и защита бизнеса (СМЭС г. Алматы)*
  3. *Имущественные и семейные споры (раздел имущества, недвижимость, банкротство)*
- **Интерактивный квиз-калькулятор:** 4-шаговый экспресс-анализ перспектив дела с персональным расчетом.
- **Профайлы ведущих адвокатов:** Адвокат Тамара и Адвокат Нурлан с их специализацией, цитатами и прямыми кнопками записи.
- **Реальная судебная практика (Кейсы):** фильтруемые победы с суммами и статьями.
- **Интерактивная карта и контакты:** г. Алматы, ул. Богенбай батыра, 23а.
- **Быстрые кнопки связи:** звонок в 1 клик, прямой диалог в WhatsApp 24/7.

### 2. Личный кабинет администратора / CRM (`admin.html`):
- **Дашборд показателей (KPI):** общее число лидов, новые заявки, назначенные консультации, заключенные договоры, конверсия (%).
- **Управление заявками:**
  - Изменение статуса (*Новая*, *В работе*, *Консультация*, *Договор*, *Отказ*).
  - Поиск по имени, телефону или тексту дела.
  - Фильтрация по статусам.
  - Добавление и сохранение заметок адвоката по каждому делу.
  - Прямой переход в WhatsApp к клиенту с готовым шаблоном обращения.
- **Экспорт данных:** выгрузка всех заявок в Excel (CSV).
- **Интеграция с Telegram:**
  - Ввод Telegram Bot Token и Chat ID.
  - Кнопка «Проверить отправку» тестового сообщения.
  - Моментальное получение заявок прямо на смартфон адвоката в Telegram.
- **Генератор тестовых заявок:** кнопка «Тестовый лид» для демонстрации работы воронки.

## 🚀 Как запустить и использовать

1. **Для просмотра сайта:**
   - Просто откройте файл `index.html` в любом браузере (Chrome, Edge, Safari, Firefox).
2. **Для работы с заявками:**
   - Откройте `admin.html` или нажмите кнопку «Кабинет админа» в шапке / футере сайта.
3. **Настройка Telegram-уведомлений:**
   - Перейдите в `admin.html` в блок «Мгновенные уведомления в Telegram».
   - Укажите Token вашего бота (из @BotFather) и Chat ID (из @userinfobot).
   - Нажмите «Сохранить настройки» и «Проверить отправку».
